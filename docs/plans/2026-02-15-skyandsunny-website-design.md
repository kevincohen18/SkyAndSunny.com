# SkyAndSunny.com Website Design

## Overview
A fun, bright showcase website for Sky and Sunny — two green cheek conure mutations.
Sunny is the TikTok star (12K followers, 900K likes, 13M views) with Sky as her co-star.
The TikTok handle is @SkyAndSunny.com, matching the domain.

## Tech Stack
- Static HTML5 single page
- Tailwind CSS via CDN (no build step)
- Vanilla JS for animations (scroll-reveal, stat counters, smooth scroll)
- GitHub Pages for free hosting

## Color Palette
- Sunny tones: Yellow (#F5C518), Green (#7EC883), Sky Blue hint (#87CEEB)
- Sky tones: Violet (#7B68EE), Deep Blue (#4169E1)
- Background: Warm cream (#FFF9F0)
- Text: Dark charcoal (#2D2D2D)
- Gradients blending Sunny yellow -> Sky violet for accents

## Typography
- Google Fonts: Quicksand (headings), Nunito (body)
- Playful, rounded, friendly feel

## Page Sections

### 1. Navigation
- Sticky top nav with smooth-scroll links
- Logo/brand text "Sky & Sunny"
- Links: Home, Sunny, Sky, Videos, TikTok (external)
- Mobile hamburger menu

### 2. Hero Section
- Large bold title "Sky & Sunny"
- Subtitle: "Two Green Cheek Conures Taking Over TikTok"
- Animated stat counters: 12K Followers | 900K Likes | 13M Views
- CTA button: "Watch on TikTok" linking to @SkyAndSunny.com
- Decorative feather/bird silhouette graphics (CSS)
- Yellow-to-violet gradient background accent

### 3. Meet Sunny (Star Section)
- Large placeholder image area (circle or rounded card)
- Name: "Sunny" with star/crown icon
- Species: Yellow-sided Green Cheek Conure
- Colors: Yellow and greenish with slight blue hint
- Personality bio placeholder
- "The Star" badge/label
- Fun facts list

### 4. Meet Sky
- Placeholder image area
- Name: "Sky"
- Species: Green Cheek Conure (blue/violet mutation)
- Colors: Blue/violet
- Personality bio placeholder
- "The Co-Star" badge/label
- Fun facts list

### 5. TikTok Highlights
- Grid of 6 placeholder video cards
- Each card: thumbnail placeholder, title, view count placeholder
- Link to TikTok profile

### 6. Footer
- TikTok link
- Copyright: "SkyAndSunny.com"
- Decorative feather element

## Design Principles
- Mobile-first responsive
- Bright & playful aesthetic
- Scroll-reveal animations (fade in on scroll)
- Animated number counters for stats
- Smooth scrolling between sections
- Placeholder-friendly (easy to swap in real photos/videos later)
